# Billy's Adventure

Игра в стиле "Darkest Dungeon" с элементами RPG.

## Структура проекта

```
src/
├── assets/            # Ресурсы игры
│   ├── images/        # Изображения
│   ├── audio/         # Аудио файлы
│   └── fonts/         # Шрифты
├── css/               # CSS стили
├── js/                # JavaScript файлы
│   ├── components/    # Компоненты интерфейса и игровые системы
│   ├── core/          # Основные файлы игры
│   ├── entities/      # Сущности игры (персонажи, враги)
│   ├── events/        # События и диалоги
│   └── utils/         # Вспомогательные функции
└── index.html         # Главная страница
```

## Установка и запуск

1. Клонировать репозиторий
2. Открыть `src/index.html` в браузере

## Разработка

Для внесения изменений в проект:

1. Изменить соответствующие файлы в директории `src/`
2. Протестировать изменения, открыв `src/index.html` в браузере
